| effect_step | false | Add a discrete, segmented on/off figure stepped in time with the music, for staccato hits ("do do do do" stabs) where smooth chases, spins and sweeps are wrong. One call replaces one effect per segment per hit, in one undo step with one render pass. Step times: markCollection (id or exact name; range [startMs,endMs] and minStrength as effects_on_marks, each mark's text its strength) or stepsMs, an explicit list of times. segments: {axis:"around", groupId, count?} splits the group's children (e.g. a megatree's strings) into count contiguous segments (default one per child), each lit as native Set Level effects on its children; or {axis:"vertical", targetId\|targetIds\|targetSlice, count} splits the targets' height into count horizontal bands (2..100), each lit as a still band Wipe as effect_band (elements need Vixen's Location property). mode: "walk" lights width segments (default 1) and steps them one segment per hit, wrapping; "alternate" lights the even segments, then the odd ones, per hit (count 2 gives front/back halves); "stack" adds width segments (default 1) per hit from the bottom (or first segment), keeping earlier ones lit, and starts again after every segment is lit; "jump" lights width segments at seeded random positions (seed, default 1), never reusing a segment lit on the previous hit (needs width at most half of count). reverse:true walks the other way, stacks from the top (or last segment), or starts alternate on the odd segments. colors: #RRGGBB list cycled per hit (default white); a stacked segment keeps its hit's colour. level: brightness percent (default 100). Each hit lasts holdFraction (default 0.8) of the time to the next hit, so staccato gaps stay dark; stacked segments all go dark together, holdFraction of the way from the stack's last hit to the next reset. cutAtMs ends the run: later steps are dropped and the last hit ends there (times holdFraction); without it the last hit lasts as long as the median gap between hits. layerId puts every effect on a layer. Returns effectIds, steps used, segments and skipped steps. |
