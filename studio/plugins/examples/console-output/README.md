# Console Output (example)

The tutorial plugin, in Python with `vixen_plugin.py` (a copy of `studio/plugins/sdk/python/vixen_plugin.py`).
A controller type that prints the channel values it gets to its log. Try it:

    vixen-studio-mcp plugin validate .
    vixen-studio-mcp plugin run . --seconds 3

Then link the folder in Settings ▸ Plugins (or `plugin_link_dev`) and add a "Console (example)" controller to a show.
