# Security policy

Please report security problems privately, not in public issues:
**Security ▸ Report a vulnerability** on this repository (GitHub private vulnerability reporting).

Include what you found, how to reproduce it, and the version or commit. You'll get a reply within a few days.
This is an unofficial community project maintained by one person with help from an AI maintainer agent; fixes are
released on the default branch.

Out of scope: problems in upstream Vixen Lights itself (report those to the Vixen team), and anything that needs
physical access to the machine running the app.
